## 更新约定

1. 每完成一项实际工作，就更新对应文档和本页进度。
2. 每篇论文使用独立笔记，例如 `01-paper-short-name.md`；复现使用同名独立目录。
3. 笔记区分论文原文观点与个人理解；代码、图片、数据及其他引用注明来源。
4. 仅记录真实运行的实验结果，不将模板、计划或预期指标标成已完成。
5. 小步提交并及时推送。首次配置和常用命令见 [仓库使用说明](SETUP.md)。
